# Astro Orb - AI-Powered Astrology Telegram Mini App

Astro Orb - это AI-powered Telegram Mini App для астрологических чтений с TON-платежами. Приложение предоставляет БЕСПЛАТНЫЕ натальные карты (расчёт через Python с Swiss Ephemeris для NASA-точности), солярные возвраты, гороскопы, совместимость, Ба Цзы, систему рефералов, уровни подписки ($9/$15/месяц) и энергетические пакеты через TON.

## Технологический стек

- **Frontend**: React + Vite, TypeScript
- **Backend**: Express + TypeScript  
- **База данных**: PostgreSQL через Drizzle ORM
- **AI**: OpenAI GPT-5 через Replit AI Integrations
- **Астрология**: Swiss Ephemeris (NASA-точность)
- **Blockchain**: TON для платежей
- **Стиль**: shadcn/ui + Tailwind CSS

## Персонализация тональности ИИ

Все текстовые ответы Astro Orb теперь адаптируются под пол пользователя.
Женщинам тексты выдаются в более тёплом и чутком тоне, мужчинам — в конкретном и уверенном, но при этом человечном.
Это касается всех модулей: натальных и солярных карт, гороскопов, совместимости и индивидуальных вопросов.

### Как это работает

1. **Функция персонализации** (`personalizeTone` в `server/lib/openai.ts`):
   - Для женщин: мягкий тон с акцентом на понимании и поддержке
   - Для мужчин: конкретный и уверенный тон с сохранением тепла
   - Для других: нейтральный баланс между теплом и конкретикой

2. **Markdown промпты** в `server/lib/prompts/`:
   - `natal.md` - натальные карты
   - `solar.md` - солярные возвраты  
   - `horoscope.md` - гороскопы
   - `compatibility.md` - совместимость
   - `ask.md` - индивидуальные вопросы
   - `planet.md` - интерпретации планет

3. **Автоматическая интеграция**: пол пользователя передается во все функции AI автоматически.

## Основные функции

- **Натальная карта** (БЕСПЛАТНО): точный расчёт через Swiss Ephemeris с AI-интерпретацией
- **Интерактивные планеты**: кликабельная визуализация с персональными интерпретациями
- **Солярный возврат**: прогноз на год (2 орба энергии)
- **Гороскопы**: день/неделя/месяц (1-3 орба)
- **Совместимость**: анализ отношений (2 орба за карту партнёра)
- **AI-вопросы**: персональные ответы (1 орб)
- **Система энергии**: геймификация с ежедневным сбросом
- **TON-платежи**: подписки и энергетические пакеты
- **Реферальная программа**: +1 орб за приглашённого друга

## Локализация

Полная поддержка русского и английского языков, включая AI-ответы.

## Безопасность

- JWT-аутентификация (30 дней)
- Валидация Telegram InitData (HMAC-SHA256)
- Верификация TON-транзакций с защитой от replay-атак
- Type-safe кодовая база (TypeScript + Zod)
