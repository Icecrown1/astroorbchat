Задача: улучшить визуализацию натальной карты в Astro Orb (модуль `ChartCanvas.tsx`), не меняя астрологические расчёты, а только визуальную часть. Применить описанные улучшения — более насыщенные цвета, контрастные символы знаков зодиака, равномерную жирность шрифта и более точное разделение секторов.

## Изменить

### Компонент
`apps/web/src/components/ChartCanvas.tsx`

### Требования
1. **Цветовая палитра**
   - Сохранить существующие оттенки фона, но сделать **поля заполненными полностью** (никаких прозрачных промежутков между секторами).
   - Использовать мягкие пастельные оттенки для зодиакальных зон (например, комбинации светло-фиолетового, мятного, песочного, голубого, лососевого, серо-лавандового).
   - Границы секторов и оси домов нарисовать тонкой, но чёткой линией (`ctx.lineWidth = 1.2`, цвет `rgba(0,0,0,0.3)`).

2. **Символы зодиака**
   - Все 12 знаков отрисовывать контрастным **золотым или бронзовым оттенком**, с лёгким свечением (эффект внутренней тени/обводки).
   - Пример цвета: `#cfa24b` (золото) или `#b87436` (бронза). Можно использовать `ctx.shadowColor = 'rgba(207,162,75,0.5)'`, `ctx.shadowBlur = 6`.
   - Размер символов = 20–24px, одинаковый для всех знаков.
   - Шрифт: `'Noto Sans Symbols2', 'Symbola', sans-serif'`.
   - `ctx.font = 'bold 22px "Noto Sans Symbols2"'`.
   - Все символы выровнены по центру каждой 30° зоны.

3. **Равномерность и жирность**
   - Установить одинаковую жирность для символов планет и знаков (`fontWeight: 600–700`).
   - Если используются Unicode-символы планет — применить `ctx.textAlign = 'center'`, `ctx.textBaseline = 'middle'`.
   - Использовать единый цвет текста для планет — `#222` на светлом фоне.

4. **Точность отрисовки**
   - Разделить круг на 12 секторов точно по 30°, добавить визуальное разграничение (линии радиусов на границах знаков).
   - В центре каждого сектора сделать **мягкую заливку (fillRadialGradient)** от прозрачного к более насыщенному оттенку зоны, чтобы визуально показать расположение планет.
   - Для каждой планеты (точка на круге) — добавить небольшое свечение (`ctx.shadowBlur = 8; ctx.shadowColor = 'rgba(255, 215, 0, 0.6)'`).

5. **Заливка центра**
   - Добавить центральную заливку круга (радиус ~15% от общего) с лёгким градиентом `radialGradient` от золотисто-бежевого к прозрачному, чтобы усилить читаемость внутренней области.

6. **Выравнивание и плотность**
   - Отрегулировать радиусы так, чтобы все зоны (знаки, дома, планеты) занимали полную площадь без пустот.
   - Убедиться, что символы не обрезаются краем canvas.

7. **Шрифты**
   - Импортировать `'Noto Sans Symbols2'` через Google Fonts в `index.html` и подключить в `ChartCanvas.tsx` (если не подключен).
   - Применить для всех астросимволов единый шрифт и одинаковый масштаб (`ctx.scale` = 1).

8. **Дополнительно**
   - Опционально добавить параметр `contrastMode` в `props`, чтобы при его включении усиливались цвета и контраст.
   - Все параметры цветов и размеров вынести в объект `THEME_COLORS` в начале файла:
     ```ts
     const THEME_COLORS = {
       zodiacSectors: ['#dcd3f2', '#d8f0e1', '#f5e0c9', '#d0e6f5', '#f2d7d7', '#e2e0f0', '#e7f4d5', '#f6e7c7', '#d9f0f3', '#f2d2e0', '#f5ead3', '#dfeaf2'],
       zodiacSymbol: '#cfa24b',
       planetSymbol: '#222',
       border: 'rgba(0,0,0,0.3)',
       centerGradient: ['#f5e0b0', 'transparent'],
     };
     ```
   - Использовать эти константы при рендеринге.

### Acceptance Criteria
- Круг делится на 12 чётких секторов с ровными границами.
- Фон каждого сектора полностью залит.
- Символы зодиака видны контрастно (золотой/бронзовый оттенок).
- Толщина и шрифт всех символов выровнены визуально.
- Центр круга имеет мягкую заливку.
- Планеты подсвечиваются свечением, зоны зодиака различимы.
- Никаких TODO/заглушек в коде.
