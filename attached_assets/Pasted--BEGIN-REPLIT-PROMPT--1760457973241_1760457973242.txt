2.5 Новые роуты

Файл: apps/api/src/routes/astrology.ts — ДОБАВИТЬ:

GET /astrology/important-dates

Требует JWT. Проверяет NatalChart (иначе 409 NATAL_NOT_INITIALIZED).

Аргументы query: days=90 (по умолчанию), limit=10.

Вызывает findImportantEvents(natal.data, {from: now, to: now+days, limit}).

Отмечает, какие события разблокированы пользователем (запрос к ImportantDateUnlock).

Возвращает { ok:true, data: { events, nearestBrief: events[0]?.brief ?? null } }.

POST /astrology/important-dates/unlock

Тело: { eventKey: string } (Zod).

Если у пользователя есть активная подписка — ничего не списывать, сразу создать запись в ImportantDateUnlock.

Иначе — списать энергию feature="important_date_detail" (1), затем создать ImportantDateUnlock.

Вернуть { ok:true }. Повторные вызовы на тот же eventKey — идемпотентны (вернуть 200).

POST /astrology/important-dates/detail

Тело: { eventKey: string }.

Проверить наличие разблокировки или активную подписку. Если нет — 402 { ok:false, error:"PAYWALL" }.

Найти событие по ключу (если оно уже не в окне, пересчитать локально).

Сформировать entrada для interpretImportantDate(...) (пол, возраст, timezone, краткий срез натала).

Вернуть { ok:true, data: { title, window, whatItMeans, risks, do, dont, timingTips } }.
