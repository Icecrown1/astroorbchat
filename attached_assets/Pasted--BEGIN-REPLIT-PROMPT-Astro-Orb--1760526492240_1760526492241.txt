## Что нужно сделать

### A) Новый формат гороскопов (день/неделя/месяц)

1. **Строгая структура для ДНЯ**: разделы «Утро», «День», «Вечер» + 5 обязательных тем, упоминаемых по делу: «Деньги», «Работа», «Учёба», «Любовь», «Здоровье». В «Вечер» — короткая конкретика self-care (напр. «примите тёплую ванну», «время без телефона»). Допустимы мягкие предупреждения уровня «возможна усталость/головная боль при стрессе» без мед. диагнозов.
2. **Еженедельный гороскоп** получает кнопку «Оставить план на неделю» (платно, см. ниже).
3. **Ежемесячный гороскоп** — аналогично «План на месяц» (платно).

#### 2. Обёртка OpenAI (ИЗМЕНИТЬ ФАЙЛ ПОЛНОСТЬЮ С ДОБАВЛЕННЫМИ ФУНКЦИЯМИ)

Файл: `apps/api/src/astrology/openai.ts` — ДОБАВИТЬ экспортируемые функции:

```ts
export async function interpretHoroscope(input: {
  period: "day" | "week" | "month";
  profile: { name: string; gender: string; timezone: string };
  natal: any;         // сохранённый натал пользователя
  transits?: any[];   // опционально
}): Promise<{
  period: "day" | "week" | "month";
  date_range: string;
  summary: string;
  day_parts: { title: "Утро" | "День" | "Вечер"; advice: string[] }[];
  themes: Record<"Деньги" | "Работа" | "Учёба" | "Любовь" | "Здоровье", string[]>;
  notes: string[];
}>;

export async function generateWeeklyPlan(input: {
  profile: { name: string; gender: string; timezone: string };
  natal: any;
  week_start_iso: string; // понедельник
  transits?: any[];
}): Promise<{
  week_range: string;
  focus_map: Record<"Пн"|"Вт"|"Ср"|"Чт"|"Пт"|"Сб"|"Вс", string>;
  spheres: Record<"Деньги"|"Работа"|"Учёба"|"Любовь"|"Здоровье", string[]>;
  daily_tips: Record<"Пн"|"Вт"|"Ср"|"Чт"|"Пт"|"Сб"|"Вс", string[]>;
}>;

export async function generateMonthlyPlan(input: {
  profile: { name: string; gender: string; timezone: string };
  natal: any;
  month_iso: string; // YYYY-MM-01
  transits?: any[];
}): Promise<{
  month: string;
  weeks: { range: string; focus: string; tips: string[] }[];
  spheres: Record<"Деньги"|"Работа"|"Учёба"|"Любовь"|"Здоровье", string[]>;
  milestones: string[];
}>;
```

* Все функции читают соответствующие `.md` промпты, добавляют `toneInstruction` и используют `response_format: "json_object"` + Zod-валидацию.
* При парсинге гарантировать наличие всех обязательных полей; при ошибке — HTTP 400.

#### 3. Роуты API (ПОЛНЫЙ ФАЙЛ С ДОБАВЛЕНИЯМИ)

Файл: `apps/api/src/routes/astrology.ts` — ДОБАВИТЬ:

* `POST /astrology/horoscope`
  Тело: `{ period: "day"|"week"|"month" }`
  Требует наличие `NatalChart`; списывает энергию **как раньше** для `period="day"`; для `week|month` — также 1 сфера (используется общая фича `horoscope`). Возвращает JSON структуры `interpretHoroscope`.

* `POST /astrology/horoscope/weekly-plan`
  Тело: `{ week_start_iso?: string }` (если не передан — берём понедельник текущей недели по таймзоне пользователя).
  Подписчики — бесплатно; иначе списать `feature="weekly_plan"` (1). Возвращает `generateWeeklyPlan`.

* `POST /astrology/horoscope/monthly-plan`
  Тело: `{ month_iso?: string }` (если не передан — первый день текущего месяца по таймзоне пользователя).
  Подписчики — бесплатно; иначе списать `feature="monthly_plan"` (1). Возвращает `generateMonthlyPlan`.

* Для всех трёх роутов: если нет `NatalChart` → `409 NATAL_NOT_INITIALIZED`.
