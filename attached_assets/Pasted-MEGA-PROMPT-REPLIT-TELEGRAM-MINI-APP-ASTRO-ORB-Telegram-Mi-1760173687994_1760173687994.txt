MEGA PROMPT ДЛЯ REPLIT — СОЗДАТЬ TELEGRAM MINI APP «ASTRO ORB»

Создай полностью рабочий Telegram Mini App «Astro Orb» с оплатами через TON, ChatGPT-движком для астрологии и геймификацией. Делай монорепозиторий со следующими требованиями — без заглушек, без «TODO», без недостающих файлов. Все ключи и конфиги — через .env (а в репозитории — файл .env.sample с примерами значений). Добавь авто-проверки, линтинг и базовое покрытие тестами.

1) Технологический стек

Frontend: React + Vite + TypeScript + Telegram WebApp SDK, Zustand (стейт), React Router, TanStack Query, TonConnect UI (@tonconnect/ui-react), Day.js (таймзоны), Zod (валидация).

Backend: Node.js 20 + TypeScript + Express + Zod, OpenAI API (модель gpt-4o-mini), astronomia и astronomy-engine для карт; собственная реализация Ba Zi (Небесные стволы/Земные ветви), Prisma ORM.

DB: PostgreSQL (таблицы ниже), миграции Prisma.

Auth: Telegram initData (проверка подписи) + сессии по JWT (short-lived, refresh).

Payments: TonConnect (основной флоу), поддержка on-chain платежей в TON; прайс в USD, конвертируем в TON через TonAPI (публичные эндпойнты). Фоллбек: фиксированный курс в .env.

Deploy: Docker + docker-compose (web, api, db, nginx), готовность к Railway/Render/Fly.io.

Код-стайл: ESLint, Prettier, Husky + lint-staged, commitlint (Conventional Commits).

Тесты: Vitest (frontend), Jest (backend) + Supertest для API.

2) Бизнес-логика и геймдизайн

Ежедневная энергия: 10 «гадальных шаров» (energy). Стандартная подписка: 100 шаров/день, «Хорошая» подписка: 250 шаров/день.

Цена подписок: Standard = 9 USD/месяц, Pro = 15 USD/месяц (в TON по курсу TonAPI). Разовый докуп шаров пакетами: 20 / 50 / 120.

Реферальная система: уникальный ref_code у каждого пользователя. Бонус пригласившему: +5 шаров за подтверждённую регистрацию и +10 шаров при оплате подписки приглашённым.

Траты энергии:

Натальная карта: 2 шара

Соляр на день: 1 шар

Прогноз/гороскоп: 1 шар

Совместимость: 2 шара

Запрос «любой вопрос к ИИ»: 1 шар

Дневной ресет энергии в 00:00 локального времени пользователя (хранить timezone).

3) Фичи астрологии (конкретика)

Регистрация: имя, дата рождения (YYYY-MM-DD), время (HH:mm, опционально), место (город/страна, опционально), пол, возраст.

Натальная карта: вычислить положения планет (Sun, Moon, Mercury, Venus, Mars, Jupiter, Saturn) и основных аспектов (конъюнкция, секстиль, квадрат, тригон, оппозиция) с орбисом 6°. Использовать astronomia/astronomy-engine.

Солярная карта «на сегодня»: вычислить солнечное возвращение относительно текущей даты пользователя.

Совместимость: сопоставление двух натальных карт + краткий отчёт.

Ba Zi (четыре столпа судьбы): вычисление Небесных стволов и Земных ветвей по дате рождения; не использовать внешние API — реализовать локально.

Формирование текстов: OpenAI (gpt-4o-mini) с function-calling. Модели получают структурированные входы (JSON из расчётов) и возвращают консистентные, короткие и прикладные ответы (до 250–400 слов), без эзотерической «воды», с чёткими тезисами и советами.

6) Схема БД (Prisma) — создай миграции
model User {
  id               String   @id @default(cuid())
  tgId             String   @unique
  username         String?
  name             String
  gender           String   // "male" | "female" | "other"
  age              Int
  birthdayDate     DateTime
  birthTime        String?  // "HH:mm" or null
  birthPlace       String?  // free text
  timezone         String   @default("Europe/Moscow")
  createdAt        DateTime @default(now())
  updatedAt        DateTime @updatedAt
  energy           Int      @default(10)
  energyResetAt    DateTime
  subscription     Subscription?
  referralCode     String   @unique
  referredById     String?
  referredBy       User?    @relation("UserReferrals", fields: [referredById], references: [id])
  referrals        User[]   @relation("UserReferrals")
  payments         Payment[]
}

model Subscription {
  id            String   @id @default(cuid())
  user          User     @relation(fields: [userId], references: [id])
  userId        String   @unique
  tier          String   // "standard" | "pro"
  status        String   // "active" | "canceled" | "expired"
  startedAt     DateTime
  currentPeriodEnd DateTime
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
}

model Payment {
  id            String   @id @default(cuid())
  user          User     @relation(fields: [userId], references: [id])
  userId        String
  kind          String   // "subscription" | "energy_pack"
  tier          String?  // "standard" | "pro" | null
  energyAmount  Int?     // for packs
  amountUSD     Decimal  @db.Decimal(10,2)
  amountTON     Decimal  @db.Decimal(18,9)
  txHash        String   @unique
  status        String   // "pending" | "confirmed" | "failed"
  createdAt     DateTime @default(now())
}

model UsageLog {
  id        String   @id @default(cuid())
  user      User     @relation(fields: [userId], references: [id])
  userId    String
  feature   String   // "natal" | "solar" | "horoscope" | "compatibility" | "ask"
  cost      Int
  createdAt DateTime @default(now())
}


Создай индексы по User.tgId, User.referralCode, Payment.txHash, Subscription.userId.

В seed.ts: создай тестового пользователя, несколько оплат, активную подписку, и стартовые тарифы в README.

7) API (Express) — маршруты и контракты

Все входы валидируй через Zod. Все ответы — JSON { ok: boolean, data?: any, error?: string }.

POST /auth/telegram — принимает initData из Telegram WebApp, валидирует подпись, создаёт/обновляет пользователя, возвращает JWT + профиль с энергией.

GET /user/me — профиль, энергия, подписка, рефералы.

POST /user/update — обновление профиля (имя, пол, возраст, birthday, time, place, timezone).

GET /energy — текущее количество, дата ресета.

POST /energy/use — { feature } списывает энергию по таблице затрат и пишет UsageLog. Ошибки: недостаточно энергии.

POST /astrology/natal — считает натал по данным пользователя, вызывает OpenAI с промптом prompts/natal.md, возвращает структурированный отчёт + короткий текст.

POST /astrology/solar — соляр «на сегодня».

POST /astrology/horoscope — общий/по знаку, на день/неделю. Вход: period: 'day'|'week'|'month'.

POST /astrology/compatibility — вход: partner { name, date, time?, place? }.

POST /astrology/ask — свободный вопрос, вход: question: string.

GET /referral/code — отдаёт ref_code.

POST /referral/apply — применяет ref_code другого пользователя (один раз); начисляет бонусы.

GET /payments/price — возвращает цены: USD и эквивалент в TON (через TonAPI; фоллбек — .env курс).

POST /payments/ton/create — генерирует payload для TonConnect, ожидаем on-chain оплату.

POST /payments/ton/webhook — принимает подтверждение, верифицирует подпись/txHash, активирует подписку или начисляет энергию.

GET /.well-known/tonconnect-manifest.json — отдает манифест TonConnect.

9) Астрология — алгоритмы (без магии слов)

Натал:

Получить JDE даты/времени рождения (если нет времени — считать полудень).

Вычислить эклиптические долготы планет (Sun, Moon, Mercury, Venus, Mars, Jupiter, Saturn).

Рассчитать аспекты между ними (орбис 6°, точность до 0.1°).

Определить знак Солнца/Луны, дом для Солнца (упрощённо — Placidus либо равные дома; выбери равные дома для стабильности).

Соляр:

Найти момент, когда солнечная долгота равна натальной солнечной долготе в текущем году пользователя; использовать ближайшее UTC-время к «сегодня».

Ba Zi:

Реализовать вычисление стволов/ветвей для года, месяца, дня (и часа, если дан) по григорианской дате. Вернуть четыре столпа и стихии.

Все вычисления — в отдельных модулях astrology/*.ts. Покрой unit-тестами базовые кейсы (ожидаемые ветви/стволы для нескольких дат).
