# Настройка для модерации

Чтобы модерация могла зайти на сайт без Telegram Login Widget, выполните следующие шаги:

## 1. Добавьте переменные окружения

### Для фронтенда:
Добавьте в Replit Secrets или в `.env`:
```
VITE_ALLOW_REGISTRATION_WITHOUT_TELEGRAM=true
```

### Для бэкенда:
```
ALLOW_TEST_AUTH=true
```

## 2. Перезапустите workflow

После добавления переменных перезапустите "Start application" workflow.

## 3. Как будет работать

- **Прямой заход на сайт (не через Telegram)**: Модерация увидит кнопку "Создать профиль" вместо Telegram Login Widget
- **Через Telegram Mini App**: Всё работает как обычно, автоматический вход

## 4. Когда модерация закончится

**ОБЯЗАТЕЛЬНО** удалите ОБЕ переменные:

1. `VITE_ALLOW_REGISTRATION_WITHOUT_TELEGRAM` (фронтенд - скроет кнопку "Создать профиль")
2. `ALLOW_TEST_AUTH` (бэкенд - закроет обход аутентификации)

После удаления перезапустите workflow.

---

**⚠️ ВАЖНО**: Это временное решение только для модерации!

- Если оставить `ALLOW_TEST_AUTH=true` в production, любой сможет создать профиль без Telegram
- Обе переменные должны быть удалены после прохождения модерации
- Проверьте что переменные удалены перед публикацией
