# Мобильный прототип AstroOrbi

На главной есть переходы к карте дня, раскладу и интерактивной матрице судьбы. Таро использует общую колоду из 78 карт и ключевые слова из `shared/tarot.ts`. Карта дня сохраняется на текущую локальную дату, а недавние расклады доступны в истории на том же устройстве. Матрица использует общие формулы, дата рождения хранится в памяти открытого приложения. Эти функции работают офлайн.

## Локальный запуск

Из каталога `mobile` на Node.js 22.12+ или 24:

```sh
npm ci
npm run dev
```

## Android и iOS

В новом checkout сначала соберите ресурсы и создайте нужный проект:

```sh
npm run build
npx cap add android
npm run prepare:android
npx cap add ios --packagemanager SPM
swift scripts/prepare-ios.swift
```

Для дальнейших изменений используйте `npm run sync`. Команды `npx cap open android` и `npx cap open ios` открывают проекты в Android Studio и Xcode соответственно. Для сборки под iOS нужен macOS с Xcode. Платформенные каталоги в этом прототипе генерируются из зафиксированных версий пакетов. До первой ручной правки нативных проектов их следует добавить в Git.

Идентификатор `app.astroorbi.preview` предназначен для локального тестирования. Серверные аккаунты, платежи и рекламные SDK — следующие этапы.

Для iOS CI публикует архив `astroorbi-ios-simulator` с `App.app`. После распаковки установите его на запущенный симулятор командой `xcrun simctl install booted App.app`. Для установки на физический iPhone нужна сборка с подписью Apple Developer. Для Android CI публикует отладочный APK. Обновления поверх предыдущей сборки требуют одинаковых идентификатора приложения и ключа подписи.

## Профиль и серверное Таро

Во вкладке «Профиль» можно подключить существующего пользователя одноразовым кодом из настроек мини-аппа. Код действует 5 минут. На Android/iOS сессия сохраняется в защищённом хранилище устройства до выхода или истечения серверного срока (8 часов). В браузере сессия хранится в памяти. Мобильная карта дня с ИИ использует тот же серверный расклад и историю, что и Telegram. Офлайн-история сохраняется на устройстве.

Перед выкладкой серверной части примените к нужной PostgreSQL-базе добавочную миграцию `scripts/mobile-link-codes.sql` и разверните эту версию сервера и мини-аппа. Для тестовой сборки с отдельным сервером укажите его HTTPS-адрес в `VITE_ASTROORBI_API_URL` при сборке. По умолчанию нативный клиент обращается к `https://astroorbiapp.com`. Серверные запросы проверяйте в нативной сборке или через сервер с настроенным CORS.

На экране «Натальная» открывается карта аккаунта из общего API. Если карта ещё не построена, её можно создать по сохранённым данным рождения. Доступны колесо с выбором планеты, её положение и общий разбор карты.
