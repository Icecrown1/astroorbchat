# Мобильный прототип AstroOrbi

На главной есть переходы к карте дня, раскладу и интерактивной матрице судьбы. Таро использует общую колоду из 78 карт и ключевые слова из `shared/tarot.ts`. Карта дня сохраняется на текущую локальную дату, а недавние расклады доступны в истории на том же устройстве. Матрица использует общие формулы, дата рождения хранится в памяти открытого приложения. Эти функции работают офлайн.

## Локальный запуск

Из каталога `mobile` на Node.js 22.12+ или 24:

```sh
npm ci
npm run dev
```

## Android и iOS

В новом checkout сначала соберите ресурсы и создайте нужный проект:

```sh
npm run build
npx cap add android
npx cap add ios
```

Для дальнейших изменений используйте `npm run sync`. Команды `npx cap open android` и `npx cap open ios` открывают проекты в Android Studio и Xcode соответственно. Для сборки под iOS нужен macOS с Xcode. Платформенные каталоги в этом прототипе генерируются из зафиксированных версий пакетов. До первой ручной правки нативных проектов их следует добавить в Git.

Идентификатор `app.astroorbi.preview` предназначен для локального тестирования. Серверные аккаунты, платежи и рекламные SDK — следующие этапы.
