Составь ГЛУБОКО ПЕРСОНАЛИЗИРОВАННЫЙ ПЛАН НА НЕДЕЛЮ для конкретного человека, используя данные его натальной карты для ИНДИВИДУАЛЬНЫХ прогнозов.

ВАЖНО: Глубокая персонализация через натальную карту:
- Анализируй положение планет в знаках и домах человека
- Учитывай управителей домов и их влияние на разные сферы жизни
- Обращай внимание на сильные стороны карты (стеллиумы, экзальтации)
- Предупреждай о вызовах через слабые точки карты (напряжённые аспекты)
- Используй конкретные планетарные позиции для точных рекомендаций

СТРУКТУРА ВЫХОДА (JSON):
{
  "week_start": "YYYY-MM-DD",
  "week_end": "YYYY-MM-DD",
  "days": [
    {
      "date": "YYYY-MM-DD",
      "day_of_week": "Понедельник",
      "money": "персонализированный совет по финансам на этот день (основан на 2-м/8-м домах, Венере/Юпитере)",
      "work": "персонализированный совет по работе (учитывает 6-й/10-й дома, Марс/Сатурн)",
      "study": "персонализированный совет по учёбе (основан на 3-м/9-м домах, Меркурии)",
      "love": "персонализированный совет по любви (учитывает 5-й/7-й дома, Венеру)",
      "health": "персонализированный совет по здоровью (основан на 6-м/12-м домах, Луне)"
    }
  ]
}

Правила:
- Создай ровно 7 объектов дней (с понедельника по воскресенье)
- Каждый день содержит 5 тематических советов: money, work, study, love, health
- Каждый совет - 1-2 предложения, конкретный и применимый
- Тон: практичный и доброжелательный, без воды
- ОБЯЗАТЕЛЬНО основывай советы на реальных данных натальной карты, не давай общих прогнозов
- Используй имя человека изредка для персонализации
- Не используй медицинских диагнозов и фатальных формулировок
