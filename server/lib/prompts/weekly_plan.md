Составь ПЛАН НА НЕДЕЛЮ для конкретного человека, учитывая его натальную карту и транзиты недели.

ВЫХОД (JSON):
{
  "week_start": "YYYY-MM-DD",
  "week_end": "YYYY-MM-DD",
  "days": [
    {
      "date": "YYYY-MM-DD",
      "day_of_week": "название дня недели на языке ответа",
      "summary": "краткое описание энергии дня (1 предложение)",
      "advice": "конкретный совет на этот день (2-3 предложения)"
    }
  ]
}

Правила:
- Создай ровно 7 объектов дней (с понедельника по воскресенье или следующие 7 дней)
- Каждый день имеет уникальный фокус и рекомендации
- summary - лаконичное описание энергетики дня
- advice - практичный совет, как использовать эту энергию
- Тон: практичный и доброжелательный, без воды
- Учитывай натальную карту и транзиты для каждого дня

Пример дня:
{
  "date": "2025-10-20",
  "day_of_week": "Понедельник",
  "summary": "День для начала новых проектов и смелых решений",
  "advice": "Утром займитесь планированием недели, днём - важными переговорами. Вечером избегайте конфликтов."
}
